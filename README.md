# Учебный эксперимент с нулевой ценой

Статические страницы учебного опроса по поведенческой экономике. Участник выбирает между двумя конфетами при разных ценовых условиях. Выбор гипотетический: выдачи товара и платежей нет.

## Версии опроса

| Путь | Назначение |
| --- | --- |
| [index.html](index.html) | исходная версия опроса: выбор конфеты, вопрос о вкусе и знакомстве с экспериментом |
| [study-v7/index.html](study-v7/index.html) | отдельная версия второго сбора: вопрос о вкусе до показа цен, минимальное время показа предложения и собственный формат кода |
| [study-v7/PROTOCOL.md](study-v7/PROTOCOL.md) | зафиксированные правила второго сбора, остановки, исключений, кодирования и анализа |

Страницы используют HTML, CSS и JavaScript; отдельный этап сборки не требуется. Опубликованные версии: [исходный опрос](https://valorin777.github.io/focus-plus/) и [study-v7](https://valorin777.github.io/focus-plus/study-v7/).

## Данные и интерпретация

Первую и вторую версии, их коды и данные необходимо учитывать раздельно. Они отличаются порядком вопросов и схемой кодирования; объединять их в одну выборку нельзя.

Согласно [протоколу study-v7](study-v7/PROTOCOL.md), 59 ранее введённых кодов не являются результатами реального опроса. Они допустимы только как явно обозначенная демонстрация расчёта и не входят в новую эмпирическую выборку. Демонстрационные расчёты не подтверждают эффект нулевой цены.

Для второго сбора правила анализа и критерии включения определены в протоколе. Результат исследования заранее не предполагается; описание проекта само по себе не является отчётом о полученных данных.
